# Home Server Containers

Container images maintained by the Home Server Project.

## Images

- [Caddy + Cloudflare DNS](./caddy-cloudflare/) — Caddy built with the Cloudflare DNS provider module.

- [PicoLobby](https://github.com/nobuildersnotools/PicoLobby) - An ultra-lightweight, multi-version Minecraft lobby server written in Rust - a fork of PicoLimbo.

Stable images are published to GHCR with the `:stable` channel tag.
